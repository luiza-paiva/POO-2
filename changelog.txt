ENTREGA PARCIAL 02
------------------------------------------------------------
Adicionado - Infraestrutura (Docker)
- docker-compose.yml: sobe três serviços em contêineres: postgres
  (PostgreSQL 16), neo4j (Neo4j 5) e api (FastAPI). Os bancos só são
  acessados pela API, dentro da rede do Docker.
- Dockerfile (API/): imagem da API em Python 3.12.
- Volumes pg_data e neo4j_data, para os dados não se perderem ao
  recriar os contêineres.
- Verificação de saúde (healthcheck) nos dois bancos; a API só inicia
  depois que ambos estão prontos.
- .env: senhas dos bancos fora do código (não versionado).
- MANUAL.md: manual de execução e comandos úteis.

Adicionado - Bancos de dados
- PostgreSQL (fonte da verdade): tabelas usuarios, generos, filmes,
  alugueis e avaliacoes (DADOS/esquema.sql), com chaves estrangeiras,
  CHECK (tipo da conta e nota de 1 a 5), UNIQUE (uma avaliação por
  usuário e filme) e ON DELETE CASCADE (excluir filme remove as
  avaliações).
- Aluguel ativo é o registro sem data_devolucao; um índice único
  parcial impede dois aluguéis ativos do mesmo filme. A tabela
  alugueis substitui o alugueis.csv como histórico.
- Neo4j (grafo de recomendação): nós Usuario, Filme e Genero, relações
  ALUGOU e DO_GENERO, com constraints de unicidade
  (DADOS/esquema.cypher). Guarda só login, id, título e gênero; senha
  e datas ficam apenas no PostgreSQL.
- Justificativa do armazenamento: PostgreSQL para dados estruturados,
  transações e integridade; Neo4j para as relações entre usuários e
  filmes (recomendação); arquivos continuam para pôsteres, preferência
  de tema e exportação do histórico em .txt.

Adicionado - API (FastAPI, pasta API/)
- main.py: aplicação, rota /saude e inicialização (constraints do
  Neo4j, administrador padrão, gêneros e catálogo inicial de 15 filmes).
- db.py: conexões com PostgreSQL e Neo4j, configuradas por variáveis
  de ambiente.
- usuarios.py: POST /usuarios/cadastro e POST /usuarios/login, com
  senha guardada em hash (bcrypt).
- filmes.py: GET e POST /filmes, PUT e DELETE /filmes/{id} e
  GET /filmes/generos. A listagem traz status, quem alugou, média e
  quantidade de avaliações.
- alugueis.py: POST /alugueis, POST /alugueis/devolucao e
  GET /alugueis/historico. Só quem alugou o filme pode devolvê-lo.
- Gravação em duas etapas: primeiro no PostgreSQL, depois replicada no
  Neo4j com MERGE. Se o Neo4j estiver fora do ar, o sistema continua
  funcionando.

Adicionado - Interface
- telaFilme.py: classe TelaFilme, tela individual do filme, aberta ao
  clicar no card. Mostra pôster grande, título, etiquetas de gênero e
  status (Disponível ou Alugado por <usuário>), nota média, sinopse e
  as avaliações dos usuários (estrelas e comentário).
- TelaFilme: o usuário comum vê os botões Alugar/Devolver filme e
  Avaliar filme; o Admin vê Editar filme e Excluir. Os botões chamam
  os métodos da janela principal, então as regras continuam as mesmas,
  e a tela se atualiza depois de cada ação.
- TelaFilme: o botão fica "Indisponível" (desabilitado) quando outro
  usuário alugou o filme. Avaliar filme fica desabilitado, com a dica
  "Alugue este filme para poder avaliá-lo", se o usuário ainda não
  alugou, e vira "Editar minha avaliação" se ele já avaliou.
- Janela principal: cabeçalho com saudação ("Olá, <login>") e dica de
  uso, de acordo com o tipo de conta.
- Janela principal: a busca filtra enquanto o usuário digita (o botão
  "Buscar" foi removido) e mostra uma mensagem quando nenhum filme é
  encontrado.
- Janela principal: botões de filtro por gênero (Todos, Romance, Ação,
  Drama, Terror e Ficção científica), que funcionam junto com a busca.
  O menu Gênero ganhou a opção "Todos os gêneros".
- cartaoFilme.py: card redesenhado, menor, com selo Disponível/Alugado
  sobre o pôster, título e nota média (ex.: ★ 4,5 (2)) ou "Sem
  avaliações".
- cartaoFilme.py: setas ‹ e › em cada fileira para rolar os filmes,
  exibidas só quando há mais filmes do que cabem na tela. A roda do
  mouse sobre a fileira rola a página.
- EstrelasWidget (dialogos.py): nota de 1 a 5 em estrelas clicáveis,
  usada na JanelaAvaliar no lugar do QSpinBox.
- JanelaCadastro (dialogos.py): novo campo Sinopse, usado ao cadastrar
  e ao editar um filme.
- posters/: pôsteres dos 15 filmes do catálogo inicial.

Adicionado - Código
- Filme (models.py): novo campo sinopse. O from_dict lê o campo com
  .get, então o filmes.json antigo continua carregando.
- SINOPSES (repositorio.py): sinopse dos 15 filmes iniciais.
  RepositorioFilmes.carregar preenche a sinopse dos filmes do catálogo
  inicial que ainda não têm e grava o arquivo.
- cartaoFilme.py: funções formatar_nota, nome_arquivo_poster,
  caminho_poster e gerar_poster (pôster com cantos arredondados).
- Janela.definir_genero: guarda o gênero escolhido e marca o botão de
  filtro correspondente.
- Janela.ja_alugou: verifica no histórico se o usuário já alugou o
  filme.
- tema.py: ESTILO_APP e função estilo_app(), com o estilo dos cards,
  fileiras, filtros, busca e tela do filme nos temas claro e escuro.

Alterado
- cartaoFilme.py: o pôster agora é procurado em posters/<título>.jpg

- cartaoFilme.py: o sinal clicado passou a enviar o id como texto

- Janela.atualizar_lista: passa a aplicar a busca e o gênero

  Também calcula a média e a quantidade de avaliações exibidas no card

- Janela.selecionar_filme: além de marcar o card, abre a TelaFilme.
- Janela.filtrar_por_genero: passa a chamar definir_genero.
- Janela.buscar_filme: removido, pois a busca agora é feita em
  atualizar_lista a cada letra digitada.
- Janela.avaliar_filme: a verificação de aluguel passou para
  ja_alugou.
- Janela.excluir_filme: limpa o filme selecionado depois de excluir.
- Janela.cadastrar_filme e Janela.editar_filme: passam a gravar a
  sinopse.
- JanelaAvaliar: a nota é escolhida em estrelas (EstrelasWidget).
- tema.py: os estilos dos cards (_QSS_COMUM, _QSS_ESCURO e _QSS_CLARO)
  foram substituídos por ESTILO_APP. O fundo do tema claro foi
  clareado (de 220 para 240).

ENTREGA FINAL - TRABALHO 3
------------------------------------------------------------

Adicionado - API (FastAPI, pasta API/)
- avaliacoes.py: POST /avaliacoes e GET /avaliacoes/{filme_id}. A
  avaliação (nota de 1 a 5 e comentário) só é aceita se o usuário já
  alugou o filme; caso contrário, a API responde 403. Avaliar de novo
  atualiza a avaliação anterior (INSERT ... ON CONFLICT DO UPDATE). A
  listagem traz usuário, nota, comentário e data/hora, da mais recente
  para a mais antiga.
- main.py: o router de avaliações foi registrado na aplicação.

Adicionado - Cliente da API (clienteApi.py)
- cadastrar: cria conta via POST /usuarios/cadastro (retorna False se
  o login já existe).
- listar_filmes: busca o catálogo em GET /filmes.
- alugar e devolver: chamam POST /alugueis e POST /alugueis/devolucao
  (função auxiliar _enviar).
- historico: busca o histórico em GET /alugueis/historico, com filtro
  opcional por usuário.
- cadastrar_filme, editar_filme e excluir_filme: chamam POST, PUT e
  DELETE em /filmes (função auxiliar _requisitar).
- Todas as funções tratam API fora do ar e levantam ErroApi com a
  mensagem de erro.

Alterado - Interface (a aplicação passa a usar a API)
- JanelaLogin: o login e a criação de conta agora são feitos pela API
  (clienteApi.login e clienteApi.cadastrar), no lugar do
  registroUsuarios local (usuarios.json). Erros da API aparecem em
  uma caixa de diálogo.
- Janela.carregar_filmes_da_api: novo método que carrega o catálogo
  pela API; substitui a leitura de filmes.json na abertura.
- Janela.cadastrar_filme: cadastra o filme pela API e recarrega o
  catálogo.
- Janela.abrir_alugar: o aluguel é registrado pela API e o catálogo é
  recarregado.
- Janela.ja_alugou: verifica o aluguel no histórico da API.
- Janela.abrir_historico: o histórico vem da API (Admin vê todos;
  Usuário vê só os seus), no lugar do alugueis.csv.
